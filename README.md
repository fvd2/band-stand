# Band Stand

A family music looper that runs in the browser. Build a song one part at a time: drums, bass, guitar, piano, synth and your own voice, each on its own track with effects.

Play it at **https://fvd2.github.io/band-stand/**

## What it does

- Tracks with record buttons, mute and solo, and a loop of 1 to 16 bars.
- Drum tracks with five kits and pads you can add, remove, retune and layer.
- Per-track effects: drive, filter, delay, reverb, plus sweeps, an arpeggiator and kick ducking.
- Song sections (A, B, C…) that play in an order you choose.
- Scale lock so every key fits, a note editor, MIDI keyboard input (Chrome and Edge), microphone recording, and audio export as WAV.

Songs are saved in the browser. Use **Save song file** to move a song between devices.

It is one static `index.html` with no build step.
